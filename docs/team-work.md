# Team Work

## Member 1 — Employee
Owns `dayflow_core`, employee creation, employee code, groups, access rules and profile.

## Member 2 — Attendance
Owns `dayflow_attendance` and dashboard attendance/status widgets.

## Member 3 — Leave
Owns `dayflow_leave` and notifications for leave approval/rejection.

## Member 4 — Payroll
Owns `dayflow_payroll`, salary formulas and payable-day calculations.

Integration rules:
- Do not rewrite another member's module without coordination.
- Use pull requests.
- Test module installation before merging.
- Never commit passwords, API keys or database dumps.
