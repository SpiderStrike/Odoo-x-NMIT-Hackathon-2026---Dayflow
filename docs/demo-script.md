# Demo Script

1. HR creates an employee.
2. System generates the Dayflow Employee ID.
3. Employee opens the profile in view-only mode.
4. Employee checks in and later checks out.
5. Dashboard reflects attendance/status.
6. Employee submits Paid Time Off, Sick Leave or Unpaid Leave.
7. Sick leave can include a medical certificate.
8. HR approves/rejects the request.
9. HR opens salary structure and changes wage.
10. Salary components recalculate.
11. Payroll uses approved leave/attendance inputs to calculate payable days.
12. HR views payroll; employee cannot access salary records.
